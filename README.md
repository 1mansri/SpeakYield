# Speak Yield — Planning Docs

Living planning reference for **Speak Yield**, a voice-first agri-commerce platform for India's smallholder farmers. Generated at idea/prototype stage, before code.

> **Sources:** `Speak_Yield_Product_Overview_Guide.md` + `Speak Yield.pdf` (10-slide pitch deck).
> **Confirmed decisions** (see [DECISIONS.md](./docs/DECISIONS.md)): single shared marketplace · phone+OTP (KYC-gated business accounts) · voice-assisted with explicit confirm · AWS Mumbai residency, cross-border STT/LLM with consent.
> ⚠️ Items marked with ⚠️ are reasoned assumptions to confirm. Legal docs are drafts requiring counsel review.
